# GKI Gejayan - Full-Stack Modern Church Website

A premium, full-stack website for GKI Gejayan inspired by JPCC.org, featuring a clean visual language, dynamic data management, and a mobile-first responsive design.

## Tech Stack
- **Frontend**: React (Vite), Tailwind CSS, Framer Motion, Axios, Lucide React.
- **Backend**: Node.js, Express.js, Mongoose (MongoDB).
- **Design System**: Palette 2 (Earth tones/Cement/Wood).

## Prerequisites
- Node.js (v16+)
- MongoDB (Running locally or Atlas)

## Getting Started

### 1. Setup Backend
```bash
cd server
npm install
cp .env.example .env
npm run dev
```

### 2. Setup Frontend
```bash
cd client
npm install
npm run dev
```

## Folder Structure
- `/client`: React application (Frontend).
- `/server`: Express API (Backend).
- `/client/public`: Assets (Images provided as references).

## Highlights
- **Visual Storytelling**: High-impact hero section and interior galleries.
- **Service Management**: Dynamic schedules pulled from the API.
- **Ministry Engagement**: Modern cards for various church commissions.
- **Responsive Navigation**: Smooth transitions and mobile-friendly menu.
